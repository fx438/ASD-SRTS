# 新标准五折传统方法实验报告

## 协议

- 数据：ABIDE-I CC400，860 人，392 个非空 ROI，每人前 146 个时间点。
- 划分：严格复用正式 `splits_manifest.json`；每折 602/86/172，五个测试集互斥且覆盖 860/860。
- 特征：Pearson FC 的非对角上三角，经 Fisher-Z 变换，共 76,636 维。
- 预处理：每折仅在 602 人训练集上做双样本 t 检验并选择绝对 t 值最大的 1,200 个特征；`StandardScaler` 也仅拟合训练集。
- 选择：模型超参数固定；验证集只用于选择分类阈值；测试集不参与特征、标准化、模型或阈值选择。
- 随机性：划分固定 `seed=42`；为沿用原传统方法脚本，RF 和普通 MLP 的 estimator `random_state=0`，RBF-SVM 的概率校准也显式固定为 0。
- 汇总：五折算术均值 ± 五折 sample SD（`ddof=1`）。

## 结果

| 方法 | AUC | ACC |
|---|---:|---:|
| Logistic Regression | 0.6914±0.0502 | 0.6314±0.0398 |
| KNN | 0.6999±0.0528 | 0.6477±0.0410 |
| 普通 MLP | 0.7134±0.0493 | 0.6570±0.0318 |
| Random Forest | 0.7201±0.0473 | 0.6442±0.0438 |
| RBF-SVM | 0.7408±0.0533 | 0.6779±0.0461 |

作为描述性参照，同一锁定五折下的 BrainNetMLP 原始 FC 为 AUC 0.7474±0.0453、ACC 0.6733±0.0338；SRTS 为 AUC 0.7687±0.0465、ACC 0.6930±0.0402。传统方法中 RBF-SVM 的平均 AUC 最高（0.7408），但本文不据此作未经配对统计检验的“显著优于/劣于”表述。

## 核验

- 五种方法均通过独立重算核验。
- 每种方法均确认五折规模为 602/86/172，测试并集 860 人且每人恰好一次。
- 每折保存训练索引、测试索引、1,200 个特征索引、Scaler 摘要哈希、验证概率、测试概率和阈值。
- 验证阈值、折级指标、五折均值和 sample SD 均由保存概率重新计算并一致。
- KNN、普通 MLP、Random Forest 和 RBF-SVM 的每折特征选择及 Scaler 哈希与 Logistic Regression 完全一致。
- 五种方法训练过程均无警告。
- 正式 BrainNetMLP 主结果文件仍保持 raw AUC 0.7473617364540608、SRTS AUC 0.7686899209269589，未被本实验覆盖。
